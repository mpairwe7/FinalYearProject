# Crane Cloud requirements — slim CPU profile.
#
# Crane Cloud RENU pods are CPU-only with ~4-8 GB RAM, so the heavy
# torch / transformers / sentence-transformers / bitsandbytes stack from
# requirements.txt is intentionally OMITTED.  The app's import sites for
# those packages are all `try/except ImportError`-guarded — the runtime
# degrades to BM25 keyword retrieval and the LLM dispatches through a
# remote backend (`LLM_BACKEND=vllm` against an external endpoint).
#
# To run the local-GPU stack instead, use App/backend/requirements.txt.
