# Threat Model Reports (Generated)

Reports are generated by [Threagile](https://threagile.io) from `threagile.yaml` and are **not committed to git** (see `.gitignore`). They are also produced automatically during threat modeling validation and can be generated locally.

## Automated CI Generation on PRs

Threat modeling analysis runs automatically on PRs affecting backend, frontend, or threat model files via [`.github/workflows/threat-model.yml`](../../../../.github/workflows/threat-model.yml):
- Executes Threagile analysis and validates the Risk Register.
- Posts sticky interactive summary tables on the Pull Request.
- Uploads all report artifacts (`report.pdf`, `risks.json`, `data-flow-diagram.png`, etc.) for 90 days retention.

## Generate Locally

```bash
# From repo root
docker run --rm \
  -v $(pwd)/docs/security/threat-model:/input \
  -v $(pwd)/docs/security/threat-model/reports:/output \
  threagile/threagile:latest \
  -model /input/threagile.yaml \
  -output /output
```

## Output Files

| File | Description |
|------|-------------|
| `report.pdf` | Full threat model report with risk analysis, DFDs, and recommendations |
| `risks.json` | Machine-readable risk list (auto-detected risks) |
| `risks.xlsx` | Spreadsheet for risk review and tracking |
| `data-flow-diagram.png` | Auto-generated DFD from the model |
| `data-asset-diagram.png` | Data asset classification diagram |
| `stats.json` | Risk severity distribution summary |
| `technical-assets.json` | Technical asset inventory with properties |
| `tags.xlsx` | Tag-based asset classification |
